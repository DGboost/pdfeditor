# Changelog

## Unreleased — unified document editor

- Add content-based PDF/DOCX/HWP/HWPX/PPTX opening with explicit legacy DOC/PPT conversion guidance, ambiguous/corrupt package rejection, and PPTX conversion consent.
- Vendor pinned SuperDoc 1.46.3, rhwp 0.8.6, and PPTist source; build their isolated same-origin runtimes sequentially with licensed local fonts. Preserve the existing React/Vite/MuPDF PDF engine versions.
- Share document header, Office selection formatting, undo/redo, zoom, and action-based export controls while retaining format-specific editing panels.
- Keep embedded HWP/HWPX workspace and rulers light and omit their top diagnostic notices while preserving save-loss safeguards.
- Add HWP/HWPX native page thumbnails, collapsible page navigation, zoom/width-fit controls, and facing-page viewing without PDF conversion, PDF page assembly actions, or a right edit panel.
- Debounce HWP/HWPX page thumbnail refreshes while typing and retain previews during updates and text composition without delaying page navigation.
- Keep Office formatting and header controls visually stable and available during IME composition, preserve font-size input focus, and wait for committed input before actions while retaining engine safety guards and busy/loading states.
- Add a PDF-style HWP/HWPX top toolbar with a left all-page grid (select then Open, double-click to navigate, Escape to close), native pan/select tools followed by bold/italic/underline/font/size/color controls with retained pill styling and compact wrapping, and right-aligned selection status, on-demand plain-text Copy with disabled reasons for unsupported selections, and undo/redo. Remove the separate formatting row and HWP/HWPX multiple-line selection button while retaining native F5 keyboard selection; DOCX and PDF toolbars remain unchanged.
- Flush pending input before home, save, or format changes; retain the active editor until a candidate renders; cancel candidates without discarding the previous editor.
- Store Office immutable originals, native/internal checkpoints, and PPT media in a separate IndexedDB. Preserve PDF schema/migrations. Open Office archives as new working copies, preserve incompatible records as Blob-inclusive backups, and keep the last good checkpoint on storage/serialization failures.
- Distinguish transient worker Blob-read failures from structurally invalid documents so recovery does not quarantine valid drafts or archives.
- Expose preserved-original downloads from Office library records, including documents whose engine could not open. Restrict readable protected documents to original-only export; reject password-required HWP/HWPX opening without a hidden prompt or plaintext fallback.
- Correct DOCX effective inherited/mixed formatting, half-point sizes, Latin/CJK font resolution, input/story flush, strict export errors, optional package-part handling, and header/footer namespace preservation.
- Preserve DOCX editor focus, selection, and layout during autosave; recapture checkpoints changed during export after flushing input so continued editing does not produce stale checkpoints or routine save errors.
- Keep DOCX Shift+Enter lines at natural word spacing in the editor regardless of compatibility settings, with matching caret/hit-test geometry in body text, tables, and content controls; preserve automatic-wrap justification and original OOXML settings on export.
- Honor DOCX `w:next` on Enter at paragraph end, retaining the current style when no transition is specified and using the destination style's font/marks on a real transition without changing Shift+Enter semantics.
- Correct PPTX startup handshake ordering, 96 px/inch and 72 pt/inch dimensions, native input/history barriers, session isolation, host file/save routing, and Blob-backed media recovery.
- Document complete runtime deployment and corresponding patched-source licensing requirements. No public deployment is performed. Native Word/PowerPoint/Hancom and physical Windows/macOS IME compatibility remain unverified; browser synthetic-fixture evidence is not a universal fidelity guarantee.
- Make PPTX mixed bold/italic/underline selections uniformly enabled on the first toggle and uniformly disabled on the next, including slide text and remarks.
- Keep the same native PPTX editor usable at narrow widths with accessible slide/property drawers and a real fit-to-canvas control; retain the desktop layout.
- Match the PPTX host toolbar to PDF with a left all-slides grid and right-aligned undo/redo, retain zoom access, and remove unused host formatting controls. Open the grid with native slide previews and keyboard-safe navigation without duplicating the existing slide rail.
- Localize remaining PPTX slide controls, property options, menus, messages, and bundled templates in Korean; localize the HWP all-borders preset label while preserving document content, font identifiers, and numbering symbols.
- Add PPTX slideshow preview from the host toolbar (current slide or from the first slide) reusing the native show, inline by default with fullscreen available inside it. The editor stays mounted so document, history, and layout survive the preview; pending text and history are committed before it starts; editor hotkeys, paste, body-level dialogs, popovers, and context menus are suppressed while showing; Escape or the exit control returns to the editor and re-entry replays from the start.
- Play element animations by their authored click/with-previous/after-previous sequencing, including leading after-previous effects on slides other than the first, complete steps whose elements no longer exist, and discard animation callbacks left over from a previous step after turning or rewinding. Do not invent a slide transition for slides that have none. Start a slide's element effects only after its incoming slide transition ends, immediately when that slide has no transition, and hold an animation requested during the transition until it ends instead of playing it underneath or dropping it.
- State explicitly that original PPTX animations and slide transitions are not imported, and that animations added in the editor play only in the working copy: the exported PPTX modified copy does not carry them and reports that loss before download.
- Preserve pending PDF text edits when renaming a document; track draft-save freshness by workspace identity. Index glyph origins and prune cross-line overlap scans using actual painted bounds, retaining conservative editability checks.
- Add an explicit PDF selection-toolbar action to commit compatible selected text rows as one validated, undoable object without changing their text.
- Skip rebuilding an Office engine when its sources and the engine build script are unchanged and its published runtime exists; `FORCE_ENGINES=1` forces a full engine rebuild.
- Settle pending Office calls on terminal engine notifications or explicit disposal. Provide preserved-original and last-good-backup downloads plus confirmed recovery without bypassing normal save safeguards.
- Defer automatic Office saves during composition and resume after composition ends; keep explicit input flushes and HWP content-loss checkpoint refusal intact.
- Distinguish advisory DOCX read-only recommendations from enforced protection, including bare protection elements and foreign-namespace attributes. Exclude attached-template relationships from external-media warnings; retain warnings for images and unknown external types.
- Cache DOCX selection formatting against native state and revision, coalesce page measurements, and avoid duplicate export-error notifications.
- Preserve fractional PPTX text and table font sizes through import/export. Fetch only needed history records and cache immutable media hashes without revoking undo-restorable URLs; release cancelled slideshow animation and laser-pointer listeners.
