# pdfeditor

브라우저 안에서 PDF 원본을 표시하고 원본 텍스트와 페이지를 편집합니다. 새 텍스트·이미지·서명·사각형 삽입과 형광펜 기능은 제공하지 않습니다. MuPDF **1.28.1**을 사용합니다.

## 실행 및 검증

Node.js 22 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

`./start.sh`는 `lsof`가 필요하며 production build 후 3000번 포트에서 preview를 시작합니다. 이미 점유된 포트의 프로세스를 종료하지 않습니다. 개발 서버와 preview는 인터넷에 공개하는 운영 서버 대신 로컬 검증용으로 사용하세요.

HTTP 환경에서도 PDF 열기·복구와 글꼴 무결성 검증을 지원합니다. 원본·글꼴의 SHA-256 해시는 HTTPS와 동일하게 유지하며, Web Crypto의 `subtle`이 없는 환경에서는 `@noble/hashes`를 사용합니다. 문서·페이지·요소 ID는 `crypto.getRandomValues`로 생성한 UUID v4입니다. 이는 HTTP 전송을 보호하지 않으므로 외부에 공개하는 배포에는 HTTPS를 사용하세요.

## 편집 및 저장

- 원본 PDF는 불변 Blob으로 유지합니다. 선택만 하거나 파일명만 바꾼 문서의 PDF 다운로드는 원본 바이트 그대로입니다.
- 변경한 문서는 원본 PDF에 네이티브 텍스트와 페이지 변경을 적용하여 저장합니다. 원본에 포함된 사각형·벡터·이미지·주석은 유지하며, 화면 스크린샷으로 PDF를 만들지 않습니다.
- 원본 텍스트를 더블클릭하거나 선택 후 Enter를 누르면 편집 패널이 열립니다. 글꼴·크기·색상 등 선택 범위 서식은 이 패널에서만 바꾸며, `적용`할 때 문서 undo 한 단계로 기록됩니다. 전체 문서 글꼴·크기 적용과 중복 편집 진입 버튼은 제거했습니다. 패널 안의 undo/redo는 아직 적용하지 않은 입력에만 작동합니다.
- 도구는 손 도구와 선택만 제공합니다. 활성 버튼에 마우스를 올리면 일반 버튼은 연한 회색, 검정 주요 버튼은 짙은 회색으로 바뀝니다. 비활성 버튼은 호버 효과에서 제외하고, PDF 텍스트·페이지 썸네일 선택 영역은 원본을 가리지 않는 테두리로 표시합니다. 전환은 180ms이며 모션 감소 설정에서는 전환 애니메이션을 생략합니다.
- 편집 패널은 원본 글꼴 이름·스타일과 PDF 포함 여부를 표시합니다. 지원되는 공개 라이선스 face는 `다운로드해서 적용`으로 같은 원본 글꼴을 쓰는 **현재 초안의 run만** 바꿉니다. 다른 글꼴은 유지하며, 마지막 `적용`에서 편집과 글꼴을 실행 취소 한 단계로 확정합니다. 다운로드 후 `취소`하면 문서는 바뀌지 않습니다. OS에 글꼴을 설치하는 기능은 아닙니다.
- 지원 face는 NanumGothic/NanumMyeongjo Regular·Bold, NanumGothicCoding Regular·Bold, NotoSansCJKkr 7개 굵기, ABeeZee Regular·Italic입니다. 원본과 같은 이름·스타일이어도 제작 버전이나 글자 폭이 다를 수 있으므로 미리보기를 확인하세요. 알 수 없는 글꼴·지원하지 않는 face는 다운로드 가능하다고 표시하지 않습니다.
- 여러 원본 줄을 함께 고치려면 Ctrl/Cmd/Shift+클릭으로 선택을 추가·해제하거나 `여러 줄 선택`을 켠 뒤 각 줄을 클릭하세요. 둘 이상 선택하면 나타나는 `묶어서 편집`으로 읽기 순서의 묶음 편집 패널을 엽니다. `복사`도 복사 가능한 텍스트를 선택했을 때만 표시합니다. 패널이 닫힌 상태에서 빈 페이지 영역을 클릭하거나 Esc를 누르면 선택이 해제됩니다.
- 새 묶음은 내용을 바꾸지 않아도 `적용`해야 만들어집니다. 묶기 전 선택과 패널의 `취소`는 문서를 바꾸지 않으며, 묶음 적용은 실행 취소 한 단계입니다. 적용한 묶음은 다시 더블클릭하거나 Enter로 열 수 있고 서식 변경과 페이지 복제 후에도 묶음으로 유지됩니다.
- 묶음의 자동 줄바꿈은 지정한 폭 안에서 다시 배치되며, Enter로 넣은 명시적 줄바꿈은 유지됩니다. 원본의 첫 줄·이어지는 줄 들여쓰기와 줄 간격을 기준으로 배치하고, 묶음 밖의 본문이나 다음 페이지를 자동으로 밀어내지 않습니다.
- 저장·다운로드·페이지 이동은 열린 패널의 마지막 입력을 검증한 뒤 진행합니다. `취소` 또는 한글 조합 중이 아닐 때의 Esc는 적용 전 입력을 취소하며 확정된 문서는 바꾸지 않습니다. 패널을 편집하는 동안 빈 페이지 영역을 눌러도 입력을 버리지 않습니다.
- 원본 PDF와 확정된 편집, 사용한 다운로드 글꼴 바이트·라이선스는 이 기기의 IndexedDB에 자동 저장됩니다. 보관함에도 함께 저장하므로 이후 복구할 때 글꼴을 다시 다운로드할 필요가 없습니다. 보관함 저장은 별도 기록이며 초안을 삭제하지 않습니다. 브라우저 데이터 삭제 시 이 기록도 사라지므로 중요한 문서는 PDF로 다운로드하세요.
- 저장 형식은 v5입니다. 이전 v2/v3/v4 초안·보관함 중 삭제된 기능의 데이터가 없는 기록은 원본 PDF·글꼴 바이트, 페이지 순서와 원본 텍스트 편집을 유지하여 변환합니다. 편집기에서 삽입한 텍스트·이미지·서명(빈 서명 자리 포함)·사각형 또는 형광펜이 들어 있는 기록은 내용을 일부 버려서 열지 않고, 전체 원본 기록을 `이전 작업 백업`으로 보존합니다. 이러한 기록은 현재 버전에서 이어서 편집할 수 없으며 JSON 백업을 다운로드할 수 있습니다. 지원하지 않는 구버전이나 형식이 잘못된 기록도 백업으로 보존하고 다른 정상 보관함 기록은 계속 표시합니다. 백업 JSON의 Blob은 MIME 타입과 base64 바이트를 포함하며 `undefined`인 선택적 필드는 생략합니다. 백업 삭제는 명시적으로 확인해야 합니다.
- 암호는 메모리에만 보관하므로 복구 시 다시 입력해야 합니다. PDF의 본문 편집·페이지 구성·복사 권한을 각각 적용합니다.

## 보존 범위와 제한

스캔 또는 윤곽선으로 된 문자를 OCR로 만들어내지 않습니다. 원본 글꼴이 없거나 포함된 일부 문자 외의 새 문자가 필요하면 지원되는 같은 face를 명시적으로 다운로드하거나 대체 글꼴 사용에 동의해야 합니다. 다운로드 실패 시 기존 초안을 유지하며 다시 시도할 수 있습니다. 복잡한 shaping, 세로쓰기, 클리핑·겹침 또는 Unicode 매핑이 불명확한 본문은 해당 영역의 교체만 제한하며 원본 보기와 허용된 복사는 유지합니다. 페이지 밖으로 넘치거나 다른 본문과 겹치는 편집은 적용하지 않습니다.

묶기는 같은 읽기 흐름의 연속된 원본 텍스트에 한합니다. 중간 줄을 빠뜨리거나 다른 열·쓰기 방향·이미지·표 경계 등을 가로지르는 선택은 거부할 수 있습니다. 묶음이 커져 페이지 경계나 다른 본문·이미지·요소와 겹치면 적용하지 않습니다. 자동으로 글자를 줄이거나 문서 전체를 재배치하지 않으므로 내용·폭·크기를 조정하세요.

원본 PDF의 인증서 서명은 삽입 기능과 별개입니다. 문서를 수정하면 기존 인증서 서명 검증이 유지되지 않을 수 있습니다. XFA 또는 서명 위젯 페이지는 복제하지 않으며, 일반 복제본은 원본 태그 구조에 포함되지 않습니다.

문서 바이트는 서버로 전송하지 않습니다. PDF 엔진·WASM·기본 편집용 폰트는 배포 서버의 same-origin 정적 자산입니다. 텍스트를 선택하는 것만으로 외부 글꼴을 요청하지 않습니다. `다운로드해서 적용`을 누르면 필요한 지원 글꼴과 라이선스만 GitHub의 공개 원본 저장소에서 가져옵니다. 기본 제공 face는 배포 자산을 재사용합니다. 앱 UI는 시스템 글꼴을 사용하며 외부 CSS/웹폰트를 요청하지 않습니다. 흰색·회색·검정 테마는 기존 CSS 변수와 스타일 토큰으로 구현하며 Tailwind를 추가하지 않습니다. PDF 원본의 글꼴·색상과 편집용 색상 선택은 UI 테마와 별개로 유지됩니다.

## 배포 라이선스

- MuPDF는 [AGPLv3 또는 상용 라이선스](https://mupdf.readthedocs.io/en/latest/license.html)입니다. 배포자는 적용되는 AGPL 소스 제공 의무를 충족해야 합니다. 소스를 공개하지 않는 배포 정책이라면 적절한 MuPDF 상용 라이선스를 확보하기 전 배포하지 마세요.
- PDF 편집용 NanumGothic/NanumMyeongjo Regular·Bold는 Google Fonts의 원본 TTF이며 SIL Open Font License를 따릅니다. 원본 파일명·내부 이름을 유지합니다.
- 폰트 배포 시 `src/assets/fonts/nanumgothic/OFL.txt`, `src/assets/fonts/nanummyeongjo/OFL.txt`의 저작권·라이선스 고지를 함께 제공하세요. `dist`만 배포할 경우에도 이 두 고지를 포함해야 합니다.
- 추가 다운로드 face도 SIL Open Font License를 따르며 원본 라이선스 텍스트와 출처 URL을 글꼴 자산에 함께 보관합니다. 같은 이름의 상용·임의 글꼴을 검색하거나 자동 대체하지 않습니다.
